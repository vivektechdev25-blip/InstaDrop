# Database

ReelSaveHub stores **no Instagram media or credentials**. The only persisted data is anonymous audit/request logging in Supabase PostgreSQL.

## `request_logs`

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` (PK) | Generated by default |
| `hashed_ip` | `text` | SHA-256 hash of the client IP + daily rotating salt. Never store raw IPs. |
| `endpoint` | `text` | e.g. `/api/v1/fetch` |
| `status_code` | `integer` | HTTP response status |
| `created_at` | `timestamptz` | Defaults to `now()` |

**Rules:**
- No PII is ever stored.
- IP addresses are hashed with SHA-256 + a daily rotating salt before storage — never stored in plain text.
- No Instagram usernames, passwords, or session cookies are ever persisted (see [SECURITY.md](./SECURITY.md)).

Repository access lives in `apps/api/src/repositories/requestLogRepository.ts`; the row shape is defined in `apps/api/src/models/RequestLog.ts`.
